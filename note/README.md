This one is supposed to be a note-writing system I use all day, `weekly-note` for the week's notes, daily for daily, blablabla, it just opens whatever note in your terminal and creates it if non existent.

You can modify it with the environment variables exposed on the scripts.

```
NOTES_REGISTER_DEBUG
NOTES_REGISTER_NOTES_PATH
NOTES_REGISTER_DAILY_NOTE_OFFSET
NOTES_REGISTER_DAILY_NOTE_FOLDER
NOTES_REGISTER_WEEKLY_NOTE_OFFSET
NOTES_REGISTER_WEEKLY_NOTE_FOLDER
NOTES_REGISTER_MONTHLY_NOTE_OFFSET
NOTES_REGISTER_MONTHLY_NOTE_FOLDER
```
